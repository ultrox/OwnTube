# Language period comparison

## What this actually is
A saved comparison inside Languages between two groups: using Search Like a
Native and not using it. Each group combines multiple manually chosen date
ranges. Show whether language watch time and its share differ, with minutes per
calendar day alongside totals so unequal periods are comparable. Add a searchable
Other language picker beside the existing ? / DE / EN / BCS shortcuts.

## Why now
Marko wants to pinpoint when he used the extension and compare those periods with
times he did not. Russian and Japanese occur occasionally and need easy selection
without becoming permanent shortcuts.

## Definition of done
Two editable groups and inclusive date ranges are saved on the server and reusable
across browsers. Compare language totals, daily averages and shares with clear
deltas, retaining shared device/person scope and unknown time. Repeated dates
within a group count once; groups cannot overlap. Existing assessments remain the
source of language attribution. Other languages can be searched by name/code and
saved through the existing audited assessment flow. Desktop and phone work.

## Out of scope
Automatic detection of extension use, causal attribution, and a library of many
saved comparison projects: the user chose one reusable comparison with two groups.
Extra rare-language shortcut buttons are explicitly unwanted.

## Open risks
Days without playback cannot distinguish not watching from missing collection.
Display selected calendar days and recorded active days separately. Today's
statistics are partial. Fable was requested for design but could not respond
because of its usage limit; the two-group and server-save choices were confirmed
directly with Marko.
